# Latency targets: <slug> <kind> <address> <label>
#   tcp  host:port  TCP connect time. For hosts without a CDN in front: cloud regions, public resolvers.
#   api  URL        request time on an open keep-alive connection. Exchange APIs are behind a CDN, so a TCP connect
#                   would only measure the nearest CDN node.
#   post URL JSON   the same with a POST of that body, for an API whose CDN answers every public GET from its cache
#                   (the request would never reach the exchange).
# A target whose request changes gets a new slug, so its old and new values are never compared. manifest.json lists
# the slugs (CI checks it); changing the list is a minor version of the latency test.
# Only public ping/time endpoints, 10 requests each.
